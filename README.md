# LichtVernichter — тёмная тема для сайтов без неё

Расширение Google Chrome, включающее тёмную тему на выбранных пользователем сайтах.
Собственный движок пересчитывает цвета страницы: светлые фоны становятся тёмными
поверхностями палитры Material Design, текст и иконки меняются только там, где
изменился фон под ними. Фирменные цвета, фотографии и собственные цветовые пары
сайта сохраняются.

Метод — обработка элементов: движок читает итоговый (вычисленный) стиль каждого
элемента и меняет только нужные цвета атрибутами и одной своей таблицей стилей, не
трогая CSS сайта. Подробнее — [03-engine.md](docs/03-engine.md).

Автор — не профессиональный разработчик, а новичок, изучающий программирование на практике.

## Стек

- **Chrome Manifest V3** — service worker, динамическая регистрация content scripts,
  offscreen-документ;
- **JavaScript без зависимостей** — ни библиотек, ни сборки;
- **OKLCH (CSS Color 4) и WCAG 2** — пересчёт светлоты без искажения оттенка,
  контроль контраста.

## Особенности

- Работает только на сайтах из списка: на остальных скрипты расширения не
  загружаются вовсе;
- Сайт добавляется в список одним переключателем; настройка сохраняется локально и
  действует при всех последующих открытиях;
- Контраст текста не ниже 4,5 : 1, в том числе при наведении (`:hover`) и фокусе (`:focus`);
- Поздние стили, CSS-in-JS, фреймы с других доменов, открытые shadow root;
- Тёмные монохромные иконки инвертируются, фото товаров остаются видимыми;
- Не собирает данные.
