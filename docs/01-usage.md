# 01. Установка и использование

## Установка

1. Открыть `chrome://extensions` и включить **Режим разработчика (Developer mode)**.
2. **Загрузить распакованное расширение** → выбрать папку `src`.
3. Закрепить иконку на панели: значок пазла → булавка.

Минимальная версия Chrome — 126. После обновления файлов — кнопка ↻ на `chrome://extensions`.

## Окно настроек

| Элемент                                 | Действие                                                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Выключатель в заголовке LichtVernichter | Включает и выключает расширение целиком. Выключено — на иконке бейдж «выкл», скрипты не загружаются ни на одном сайте.          |
| **Тёмная тема на &lt;сайт&gt;**         | Добавляет открытый сайт в список или убирает из него. Действует сразу, без перезагрузки. `www.ozon.ru` и `ozon.ru` — один сайт. |

На сайтах из списка тема включена всегда, независимо от темы ОС. Цвета — палитра
Material Design: фон `#202124`, текст `#e8eaed`.

Переключатель сайта недоступен на служебных страницах Chrome, в Chrome Web Store и
для локальных файлов: там расширения не работают.

## Встроенные фреймы

Фреймы на сайте из списка темнеют вместе со страницей, в том числе фреймы с других
доменов (виджеты, дашборды). Такой фрейм при первом показе темнеет после своей
загрузки; его домен запоминается, и дальше он тёмный с первой отрисовки. Открытый
напрямую, этот домен остаётся без темы, пока его нет в списке.
