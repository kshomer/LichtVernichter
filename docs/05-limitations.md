# 05. Ограничения

## Состояния и изменения

- `:active` и `:checked` (`input:checked + label`) не отслеживаются — они не меняют DOM;
- `:has(` перекрашивает большого предка (> 500 элементов, например
  `body:has(.modal-open)`) только при следующем перечитывании;
- Правила, изменённые на месте через `rule.style`, не отслеживаются;
- Переходы элемента на время его обработки (два кадра) отключены: анимация сайта при
  наведении на такой элемент не проигрывается;
- Переход у `::before`/`::after`, начавшийся вместе с новым классом, читается с
  промежуточным цветом.

## Недоступное расширению

- Inline-стили сайта с `!important` сильнее любой таблицы стилей;
- Закрытые shadow root;
- Иконки внешнего SVG-спрайта (`<use href="файл.svg#символ">`) с цветами внутри
  символа; иконки с `currentColor` перекрашиваются.

## Изображения

- Фотографии на белом фоне остаются белыми — как в собственных тёмных темах магазинов;
- Иконки поверх фотографии оцениваются по фону карточки и на белом фото могут быть
  бледными;
- Внутри SVG фон фигур не учитывается: тёмная фигура на светлом круге той же иконки
  осветляется вместе с фоном страницы.

## Прочее

- Фрейм с другого домена при первом показе темнеет после своей загрузки;
- После перезагрузки расширения (↻ на `chrome://extensions`) уже открытые вкладки работают со
  старым скриптом: тема видна, но переключатели действуют на них только после перезагрузки страницы;
- Первая обработка большой страницы — пауза 67–83 мс на 12 000 элементов, в основном
  работа браузера (первая раскладка, пересчёт стилей).
