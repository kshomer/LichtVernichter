# 02. Устройство расширения

## Компоненты

```
popup ──запись──▶ chrome.storage.local ──onChanged──▶ background.js (регистрация скриптов)
                                         │
                                         └──onChanged──▶ content.js (каждый фрейм сайта из списка)
                                                             │
                                                             ▼
                                                         engine.js ── color.js
                                                             │ адрес иконки / таблицы стилей
                                                             ▼
                              background.js ──изображение──▶ offscreen.js ──▶ да / нет
```

Описание рабочих файлов — в [roadmap](00-roadmap.md#рабочие-файлы); подробности — в комментариях в начале
каждого файла.

## Список сайтов

Content scripts не объявлены в манифесте. Service worker регистрирует их через
`chrome.scripting` только для адресов из списка (`*://сайт/*`, `*://www.сайт/*`) и
обновляет регистрацию на месте, без промежутка без скриптов. На остальных сайтах
Chrome не загружает скрипты расширения вовсе.

- **Добавление** — скрипты сразу внедряются в открытые вкладки сайта.
- **Удаление** — скрипт в странице останавливает движок по событию хранилища.
- **Выключатель** — регистрация снимается целиком.
- **Фреймы с других доменов** — верхний фрейм при загрузке `iframe` просит service
  worker внедрить скрипты; домен запоминается и входит в регистрацию, пока
  встраивающий сайт в списке.

## Хранилище

| Ключ                   | Значение                                      | По умолчанию |
| ---------------------- | --------------------------------------------- | ------------ |
| `enabled`              | `true` / `false`                              | `true`       |
| `site:<домен без www>` | `on` — сайт в списке; нет ключа — не в списке | —            |
| `frame:<домен фрейма>` | Сайт из списка, который встраивает этот фрейм | —            |

Страница читает только свою запись; полный список читает лишь service worker.
1 000 сайтов — около 30 КБ.

## Разрешения

| Разрешение                     | Зачем                                                                                                 |
| ------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `storage`                      | Настройки                                                                                             |
| `scripting`                    | Регистрация скриптов для сайтов списка, внедрение в открытые вкладки                                  |
| `offscreen`                    | Документ для растеризации иконок                                                                      |
| `host_permissions: <all_urls>` | Регистрация на любом добавленном сайте, загрузка иконок и CSS с других доменов, домен вкладки в popup |
