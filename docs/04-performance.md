# 04. Производительность

## Механизмы

| Механизм                                                                   | Эффект                                                                     |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Скрипты только на сайтах из списка                                         | На остальных сайтах нагрузка нулевая                                       |
| Сначала все чтения, затем все записи                                       | Нет повторных расчётов раскладки                                           |
| Не более 8 мс на кадр для перечитывания; видимая область — первой          | Страница не замирает; при прокрутке светлое содержимое не появляется       |
| Короткие задания — вперёд длинных                                          | Открытие меню не ждёт перечитывания                                        |
| Адресная перекраска при новых стилях                                       | Полное перечитывание — только для нечитаемой таблицы или > 1 000 элементов |
| Учитываются только цветовые правила и свойства                             | Служебные классы и `transform` слайдеров не вызывают работы                |
| `::before`/`::after` — только у элементов, которым CSS задаёт `content`    | Меньше чтений стиля                                                        |
| Флаг переходов — только у элементов с переходами, без правила для потомков | Нет пересчёта стилей всей страницы                                         |
| Опрос CSSOM: 0,5 с при изменениях, до 4 с в покое                          | Меньше пробуждений в долго открытых вкладках                               |
| Кэш цветовых вычислений                                                    | Меньше работы на элемент                                                   |

## Замер

Светлая страница из 12 000 элементов, сайт в списке, медиана 5 загрузок:

|                                  | Без расширения | С расширением |
| -------------------------------- | -------------- | ------------- |
| JavaScript                       | 2 мс           | ~90 мс        |
| Пересчёт стилей                  | 10 мс          | ~33 мс        |
| Все задачи                       | ~93 мс         | ~210 мс       |
| Самая долгая пауза между кадрами | 33 мс          | 67–83 мс      |

На реальных сайтах (ozon.ru, online.metro-cc.ru, gosuslugi.ru, ru.wikipedia.org)
длинных задач от расширения нет.
