# Обзор проекта и оглавление документации

## Что за проект

Расширение Google Chrome, включающее тёмную тему только на сайтах, которые
пользователь выбрал. Цвета пересчитывает собственный движок по вычисленным
стилям элементов; сторонних библиотек нет.

Как это работает, в двух словах:

- **service worker** регистрирует скрипты только для сайтов из списка;
- **движок** в странице читает цвета элементов, затемняет светлые фоны и
  поправляет контраст текста и иконок;
- **offscreen-документ** решает, нужно ли инвертировать тёмную иконку.

## Рабочие файлы

| Файл                                                                                     | Назначение                                                                                                 |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [`src/manifest.json`](../src/manifest.json)                                              | Манифест: разрешения, service worker, popup                                                                |
| [`src/common.js`](../src/common.js)                                                      | Настройки по умолчанию, палитра, ключ сайта, список внедряемых скриптов, сообщения расширению              |
| [`src/background.js`](../src/background.js)                                              | Service worker: регистрация скриптов, иконки и таблицы стилей с других доменов (без CORS и cookies), бейдж |
| [`src/content.js`](../src/content.js)                                                    | Точка входа в странице: запуск и остановка движка                                                          |
| [`src/engine.js`](../src/engine.js)                                                      | Движок: обход DOM, расчёт и применение переопределений (перекраска), отслеживание изменений                |
| [`src/color.js`](../src/color.js)                                                        | Цветовая математика: OKLCH, контраст WCAG 2, правила перекраски                                            |
| [`src/offscreen.html`](../src/offscreen.html), [`src/offscreen.js`](../src/offscreen.js) | Растеризация иконок и вердикт «тёмная иконка»                                                              |
| [`src/popup/`](../src/popup/)                                                            | Окно настроек                                                                                              |
| [`src/_locales/`](../src/_locales/)                                                      | Строки интерфейса: английский, русский                                                                     |
| [`src/icons/`](../src/icons/)                                                            | Иконки 16–128 px                                                                                           |
