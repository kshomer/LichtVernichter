# 03. Движок тёмной темы

## Принцип

Движок читает **вычисленный стиль** (`getComputedStyle`) каждого элемента — итог
каскада, где уже учтены переменные CSS, inline-стили, CSS-in-JS и таблицы с других
доменов. Новые цвета применяются атрибутами `data-lv-*` и правилами одной таблицы
расширения (`adoptedStyleSheets`). Стили сайта не меняются; выключение снимает
атрибуты и таблицу. Селекторы усилены до веса ID (`:not(#--lv)` × 3) — сильнее правил
сайта с `!important`.

## Правила перекраски

1. **Фоны.** Светлые малонасыщенные цвета (OKLCH: L > 0,6, C < 0,08) становятся
   тёмными поверхностями палитры; чем темнее оригинал, тем светлее результат —
   карточки остаются выше страницы. Тёмные и насыщенные фирменные цвета сохраняются.
2. **Текст, рамки, SVG, иконки** — только на перекрашенных фонах и только при
   контрасте ниже WCAG 2 (4,5 : 1 для текста, 3 : 1 для графики). Нейтральные
   инвертируют светлоту, цветные сохраняют оттенок; почти чёрный цветной текст
   (светлота OKLCH < 0,27) обрабатывается как чёрный.
3. **Наследование.** Изменённый цвет записывается явно; сохранённый закрепляется,
   если его мог изменить родитель.

| Свойство | Правило |
|----------|---------|
| `background-color`, градиенты | Светлые малонасыщенные → поверхности палитры |
| `color`, `fill`, `stroke` | Контраст на перекрашенном фоне |
| `-webkit-text-fill-color` полей ввода | То же, если задан явно (автозаполнение) |
| `::placeholder` полей ввода | Контраст подсказки; если светлоты не хватает, повышается непрозрачность |
| `border-*-color`, `outline-color` | Светлые нейтральные — на ступень светлее поверхности; остальные — контраст 3 : 1 |
| `box-shadow` | Светлые тени и обводки затемняются, тёмные сохраняются |
| `::before`, `::after` | Фон, градиенты, цвет текста |
| `<img>`, CSS `url()`, спрайты | Тёмные монохромные иконки инвертируются |
| Текст на фоне с картинкой | Не меняется (картинка под текстом); если картинка — значок без повтора до 64 px (стрелка списка, лупа), фоном считается цвет элемента |
| `mix-blend-mode` картинок | `multiply`, `darken`, `color-burn` на затемнённом фоне → `normal` |
| `mask-image` | Цвет фона маски — как цвет иконки |
| Поля ввода, полосы прокрутки | `color-scheme: dark`; `scrollbar-color` из палитры |

## Отслеживание изменений

| Источник | Как обрабатывается |
|----------|--------------------|
| Новые узлы | `MutationObserver`; небольшие изменения — сразу, до отрисовки |
| Классы и атрибуты | Отслеживаются `class`, `style`, `src`, `media`, `disabled` и атрибуты из селекторов (`aria-*`, `data-*`, `open`). Класс, которого нет в цветовых правилах, пропускается. Селекторы с `+`/`~` — перечитываются следующие соседи, с `:has(` — небольшие предки |
| Поздние таблицы стилей | Сравнение правил «до/после», перечитываются только подходящие элементы; таблицы с других доменов загружает service worker (только `text/css`) |
| `:hover`, `:focus` | Цепочки элементов под указателем и в фокусе; перечитывание в обработчике события |
| Переходы CSS | На время обработки — флаг `data-lv-busy` (`transition: none`) у элементов с переходами, до снятия старых цветов; переход, начавшийся вместе с классом, отменяется при чтении; флаг снимается через два кадра и только последней обработкой элемента (идущий переход сильнее `!important`) |
